## Selected Projects

### 🚗 [YaluGo](https://yalugo.com)
A vehicle-rental website with searchable listings, fleet management, application workflows, and booking enquiries. Built around a practical admin experience and lightweight integrations.

`JavaScript` · `Firebase` · `Cloudflare Workers` · `Netlify`

### 🧩 [FastForms LK](https://fastformslk.mdwebx.store)
A form-handling platform offering submission endpoints, hosted forms, dashboard tools, and integration options for websites.

`APIs` · `Form handling` · `Dashboards` · `Web integrations`

### 🛍️ THREADORA
An e-commerce experience featuring product variants, a cart, account-based checkout, order management, and a store administration interface.

`Next.js` · `TypeScript` · `Tailwind CSS` · `Firebase`

### 🏗️ [Ruwandam Construction](https://ruwandam.lk)
A responsive company website showcasing residential projects, services, and a bilingual English/Sinhala experience.

`Frontend` · `Responsive design` · `Multilingual UI`

### 🎮 [MD GAME STORE LK](https://mdgamestore.site)
A gaming-focused website for exploring titles, updates, and community content, with a responsive interface and Firebase-powered features.

`JavaScript` · `Firebase` · `UI development`

### 📡 IoT People Counter
An ESP32-based occupancy-counting project connected to Firebase, with a live web dashboard for monitoring data.

`ESP32` · `Firebase Realtime Database` · `Web dashboard`
